# Contributing

Contributions and reproducible bug reports are welcome.

- Open an issue first for large behavior changes or new mod profiles.
- Keep the tool dependency-free, readable and compatible with Windows PowerShell 5.1 where possible.
- Preserve backups, metadata/permission fields and restore behavior whenever touching UBOAT's files.
- Do not introduce network access, admin requirements, automatic downloads, silent game launches or third-party assets without clear justification and documentation.
- For bugs, include the tool version, Windows/UBOAT version, selected profile, steps to reproduce and a redacted error message. **Do not upload user-specific save files, credentials or private paths without review.**
- Test SP and MP profile counts (49 and 47), ID uniqueness, backup/restore, and a complete launcher restart.
- Source contributions are intended to be distributed under this repository's MIT license. Confirm you are entitled to contribute any code you submit.
